# メッセージオーバーレイ機能（ニコニコ風）

このリポジトリに追加した「画面上を流れるコメント（ニコニコ風）」の実装メモです。

## 構成
- 実装: [app/page.tsx](app/page.tsx) — メッセージ送信、トグル可能な設定パネル、タイマー本体
- スタイル: [app/globals.css](app/globals.css) — `.marquee-message` とアニメーション定義

## 使い方
1. 開発サーバーを起動: `npm run dev`
2. ブラウザで `http://localhost:3000` を開く
3. 画面右下の「設定」ボタンをクリックしてパネルを開く
4. 「メッセージ」欄に入力して Enter または「送信」を押す
5. 入力したコメントが右から左へ流れます（5〜6秒で消えます）

## 調整ポイント
- アニメーション時間: `app/page.tsx` 内の `ANIMATION_DURATION`（ミリ秒）を変更してください。
- 表示位置: メッセージはランダムな縦位置（10%〜90%）で表示されます。位置の振り幅は `sendMessage` の `y` 計算を変更してください。
- メッセージのスタイル変更: `app/globals.css` の `.marquee-message` と `px-2` などを編集してください。

## 備考
- メッセージは DOM から削除されるまで表示されます（アニメーション完了後に削除）。
- 将来的には WebSocket 経由でコメントを受信する仕組みを追加すると、リアルタイム配信での運用に向きます。

## WebSocket サーバー（追加済み）

このリポジトリには簡易的な WebSocket ブロードキャストサーバーを追加しています。

- サーバー実装: `server/ws-server.js`
- デフォルトポート: `4001`（環境変数 `WS_PORT` で変更可能）

使い方:

1. 依存パッケージをインストール（`ws` が追加されています）:

```bash
npm install
```

2. WebSocket サーバーを起動:

```bash
npm run ws-server
```

3. ブラウザ側は自動的に `ws://localhost:4001` に接続します（必要なら `NEXT_PUBLIC_WS_URL` で上書き）。

4. 外部クライアントからは WebSocket 接続してテキスト（または `{ "text": "..." }` の JSON）を送ると、接続中の全クライアントにブロードキャストされます。

注意点:

- このサーバーは簡易デモ用です。本番運用する場合は認証やレート制御、メッセージ検証、セキュリティ対策が必要です。
- WebSocket サーバーは別プロセスで動作します（`next dev` とは別に起動してください）。
